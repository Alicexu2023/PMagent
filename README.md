# 工厂智能体分析平台（个人轻量版）

面向产品经理/运营自用的本机智能体数据分析工具：**导入数据 → 看懂问答质量 → 定位流失 → 形成结论与动作 → 回看效果**。

- 使用方式：本机浏览器打开 `http://127.0.0.1:8000`。样表放在项目 `lists/` 或 `D:\FactoryAgentData\uploads\` 时启动会自动加载。
- 数据：按工厂智能体周报 + 会话明细分析（不是神策埋点事件流）。导入后立刻出本地结论，不依赖 API Key。
- AI 模型：可选。有 DeepSeek Key 时用来润色结论和同义表达，没有 Key 时本地归并/漏斗/图纸采用仍可用。
- 核心原则：数字准确 > 数据不足诚实提示 > 核心流程可用 > 功能数量 > 界面精细

## 快速开始

```powershell
# 1. 安装依赖（首次）
powershell -ExecutionPolicy Bypass -File install.ps1

# 2. 配置 DeepSeek Key（可选，本地分析不依赖）
# 复制 .env.example 为 .env，填入 DEEPSEEK_API_KEY=sk-xxx

# 3. 启动平台（双击 start.bat，或）
powershell -ExecutionPolicy Bypass -File start.ps1
```

浏览器打开 `http://127.0.0.1:8000`。黑色窗口请保持打开；不要关，关了服务就停。启动脚本只用英文，避免 Windows cmd 把 UTF-8 中文显示成乱码。

## 10 项分析功能

| # | 功能 | 说明 |
|---|---|---|
| 1 | 数据导入与质检 | 三表上传、字段映射、质量报告、可做/不可做分析 |
| 2 | 高频问题与真实问法 | 标准问题榜、前 20 条真实问法（频次+多样性） |
| 3 | AI 归并与同义表达 | 问法聚类、标准问题命名、同义表达（可人工修改） |
| 4 | 漏斗分析 | 默认链路、自定义步骤、流失下钻 |
| 5 | 留存分析 | D1/D7/D30、新老用户/首次问题对比 |
| 6 | 路径分析 | 提问前后各 5 步、噪声过滤、AI 解读（不表述因果） |
| 7 | 功能采用分析 | 渗透率、人均频次、使用天数、上线前后对比 |
| 8 | AI 结论 | 结论/证据/影响/原因/动作/优先级/置信度（证据校验） |
| 9 | 行动清单与效果回看 | 五状态流转、前后指标对比、AI 摘要 |
| 10 | 报告导出 | Markdown 报告（可编辑）、同义表达 CSV |

## 数据契约

### 三张表

1. **用户总表 CSV**：周报汇总，每行一个工厂（370 行），含角色/会员/分层/地区 + 本周使用指标
2. **会话表 CSV**：会话明细，每行一条提问/上传（3000 行），含会话ID/工厂ID/提问时间/问题原文/上传文件类型/智能体回答
3. **反馈表 XLSX**：可选，空表不阻塞

### 真实样表字段映射（自动识别）

| 真实列名 | 规范字段 | 说明 |
|---|---|---|
| 会话ID | session_id | 会话还原 |
| 工厂ID | user_id / factory_id | B2B 场景：工厂即用户（无传统 user_id） |
| 公司名称 | company_name | 脱敏目标 |
| 使用人角色 / 主要使用角色 | role | 用户分群 |
| 工艺类型 / 主营工艺 | process_type | 用户分群 |
| 提问时间 | event_time | 时间维度 |
| 用户问题原文 | question_text | 高频问题 / 真实问法 |
| 上传文件类型 | upload_file_type | 上传图纸采用 |
| 智能体回答 | answer_text | 回答内容 |
| 统计周期 | week_label | 周次识别 |
| 所在地区 | region | 用户分群 |
| 会员类型 | member_type | 用户分群 |
| 当前主分层 | level | 用户分群 |
| 本周上传图纸数 | upload_count | 上传图纸汇总 |

### 通用字段契约（PRD）

| 字段 | 必需性 | 用途 |
|---|---|---|
| `user_id` | 必需 | 人数、漏斗、留存、路径、功能采用 |
| `event_time` | 必需 | 时间范围、趋势、留存周期 |
| `event_name` | 必需 | 识别提问、回答、点击、业务动作 |
| `question_id` | 问答分析必需 | 唯一问题标识 |
| `question_text` | 问答分析必需 | 用户真实问法 |
| `session_id` | 建议 | 会话还原（路径分析依赖） |
| `recognized_intent` | 建议 | 识别成功率 |
| `intent_confidence` | 建议 | 低置信度提示 |
| `answer_status` | 建议 | 有效回答率 |
| `business_result` | 可选 | 业务转化 |
| `page_name` | 路径分析必需 | 页面/模块标识 |
| `feature_name` | 功能采用必需 | 功能入口标识 |
| `event_detail` | 可选 | 事件附加信息 |
| `user_properties` | 可选 | 分群属性 |

### 数据边界规则

- 无稳定 `user_id` → 不生成留存结论
- 无 `business_result` → 不生成业务转化结论
- 无 `page_name`/`feature_name` → 路径/功能采用提示不可用，退化为基于 `event_name` 的会话内路径
- 留存组样本 < 30 人 → 标注"样本不足"
- 缺字段时明确提示哪些分析不可用，不强行生成

## 指标口径（写死，改口径改代码）

| 指标 | 定义 |
|---|---|
| 使用人数 | 分析期内至少发起一次有效提问的去重 user_id 数 |
| 有效提问数 | 排除空文本、纯符号、明确测试（"测试"/"test"）后的提问数 |
| 识别成功率 | recognized_intent 非空且置信度 ≥ 0.6 的提问数 / 有效提问数 |
| 有效回答率 | answer_status 为成功/有效的提问数 / 有效提问数 |
| 重复提问率 | 10 分钟内同一用户再次询问同一标准问题的提问数 / 有效提问数 |
| 漏斗转化率 | 各步骤达标用户数 / 上一步达标用户数 |
| N 日留存率 | 首次提问后第 N 日再次提问的用户数 / 首次提问用户数 |
| Top 路径 | 按（用户,会话）去重后的路径序列频次降序，前后各 5 步 |
| 功能渗透率 | 使用功能用户数 / 符合条件用户总数 |
| 功能上线前后对比 | 上线日前后的渗透率/频次差值与变化率 |

口径常量集中在 `core/config.py`，改口径改代码即可。

## AI 边界与安全

- **AI 负责**：理解业务、归并问题、同义表达、解读指标、生成结论/行动项/回看摘要。
- **AI 不负责**：计算客观指标（全部 pandas）、编造数值、修改计算结果。
- **证据校验**：AI 输出中的每个数字必须在本地指标中找到，校验失败的内容不进入正式结论和报告。
- **脱敏**：发送模型前用正则（手机号/邮箱）+ 敏感词表替换，只发最少样本。
- **无 Key 可用**：未配置模型时，本地分析全部照常运行。
- **本地安全**：仅监听 `127.0.0.1`，数据存本机 SQLite，API Key 不写进代码/日志/报告。
